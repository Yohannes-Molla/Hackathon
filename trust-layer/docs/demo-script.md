# 5-Minute Demo Script

## 0:00 - 0:45 Identity and SSO

1. Open web portal and sign in through Keycloak.
2. Show role-based navigation (user/admin/merchant).

## 0:45 - 1:45 eKYC and AI

1. Trigger onboarding session.
2. Show Android capture flow (document + liveness).
3. Show eKYC result with risk scoring.

## 1:45 - 2:45 Card Provisioning

1. Register credential.
2. Provision virtual card and show card controls.
3. Show dynamic CVV endpoint output.

## 2:45 - 4:00 Merchant and Transaction

1. Open merchant portal and initiate payment challenge.
2. Approve signed transaction from user flow.
3. Show transaction persistence and reconciliation output.

## 4:00 - 5:00 Admin and Security

1. Open admin portal and inspect tenant/users/transactions.
2. Show risk summary and audit log endpoint.
3. Conclude with architecture and deployment readiness.
